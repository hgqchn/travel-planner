# 4A / 5A 景区别名

2026-09-11 对全部 **5,507 条已收录名录记录**逐条生成别名补充，另同步处理15条取消/降级更正。共有4,750条名录记录具有补充文件中的别名；相比原文件新增 **10,420 条简称、别名及规范写法映射**，按记录计数，跨来源重复不合并。这不是新增10,420个景区，也不是全国所有地方俗称的穷尽清单。

`aliases.json` 单独保存补充层，按原文件名、景区名称、省份、城市精确对应。`scenic_catalog.get_catalog()` 加载时合并，保留原有别名、评级、来源类别和日期。来源文件本身不被重写，业务数据库也不需要迁移。别名进入目录指纹，因此服务重启后，客户端会重新获取匹配结果。

## 生成方法

- 使用原名称的明确行政前缀和“旅游景区”“风景名胜区”等后缀提取简称。县区前缀必须属于记录所在城市；保留“公园”“博物馆”等名称组成部分，不把任意包含关系当别名。
- 比对维基百科全国4A、5A表格中的完整名称与词条链接，读取4,771条4A行、374条5A行。只采用城市对应且名称主体一致的链接；不把所在乡镇、企业、上级地域或内部场馆作为景区别名。维基页面的评级不参与本次更新。
- `alias-curated.json` 保存13组有明确来源的常用名与旧称，例如[故宫／紫禁城](https://www.dpm.org.cn/Explore.html)、[三星堆博物馆](https://www.guanghan.gov.cn/gk/xxgk/jbxxgk/fd/gqgg/1633877.htm)、[木格措](https://www.kangdingqingge.cn/)。每组指定原记录名称和来源链接，防止因同名误写其他记录。
- 新别名与既有官方匹配冲突时排除该映射，当前排除5个候选，记录于 `conflicting_aliases_skipped`。同城歧义不会任意选择一个景区，页面仍按现有规则显示已填写的等级。
- 组合景区不按标点直接拆成各成员别名；取消/降级记录同步获得对应别名，避免旧评级通过简称重新出现。

757条记录没有产生额外有效简称，包含名称本身已经简短的记录，例如“颐和园”。空数组不表示现实中没有别名。原4A快照还有一条不完整名称“（曾用名：刺树丫口景区，2023年7月变更”，本次不为该残缺行猜测名称或生成别名。

## 来源与许可

维基名称对照固定到4A修订 `94049187`、5A修订 `92939317`，下载SHA-256、固定修订URL及行数见 `aliases.json.sources`。该文件中的维基衍生名称按[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.zh-hans)使用，署名为“维基百科贡献者”；修改内容是名称规范化、与本地名录对照及筛选。逐条 `references` 标明额外名称依据，机械简称由原名称和区划生成。原名录、区划和人工补充文件的校验值见 `input_sha256`。

## 重建与验证

下载上述固定修订的简体HTML后，在项目根目录运行（仅Python标准库）：

```sh
python3 dev/build_scenic_aliases.py --wiki4a /tmp/travel-scenic-wiki.html --wiki5a /tmp/travel-scenic-5a-wiki.html --date 2026-09-11
python3 -m unittest discover -s tests -p 'test_scenic*.py'
```

本机执行解释器为 `/Library/Developer/CommandLineTools/usr/bin/python3`。更新原名录或区划后应重建补充文件，检查新增冲突并运行测试，然后重启后端。测试覆盖全部原名称的评级回归、别名加载及来源保持、常用名、跨城市与附近商店拒绝匹配、摘牌别名和AI名称修正。
