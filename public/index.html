    使用帮助

    进入项目并选好城市后，可以让 AI 整体规划，也可以先收集地点、美食，再自己按天安排。两条流程最后都要确认具体路线。

    通过示例页面逐步模拟规划操作，无需已有行程，不会修改实际数据。可随时退出。

    1. 进入项目，选择署名在弹窗中新建项目或选择已有项目；有密码时输入密码。随后选择已有用户 ID，或创建自己的 ID，用来标记你的修改。
    2. 方式一：AI 整体规划选择“整体规划：地点＋美食＋行程”，填写日期和偏好，生成后核对、编辑并保存草稿。不必提前新增日期。
    3. 方式二：自己按天安排选择“只收集地点和美食”，确认保存清单；再“新增一天”，从时段旁的“添加地点”选入多个地点，也可以自行填写活动。
    4. 共同最后一步：规划路线每天点击“规划路线”，确认各地点的地图位置及交通方式，逐段规划并自动保存路线。不满意可在当天“更多”中选择“AI 重排这一天”，确认新草稿后重新核对路线。

    按操作查看

    如何进入项目、切换用户？

    在进入网站时的弹窗中选择已有项目，按提示输入密码；无密码项目可以直接进入。也可以选择“新建项目”，填写名称并选择是否设置密码。第一次使用时，选择已有用户 ID 或输入新的 ID；ID 是编辑署名，不需要单独设置密码。

    进入后点击页面右上角的用户 ID 可以切换署名。如果项目密码失效，请向管理员确认最新密码；切换或新建项目请使用“切换项目”；修改项目设置、管理用户与 API 密钥请使用右上角的“管理员入口”。

    如何选择城市、添加地点和美食？

    点击上方城市名称，输入中文、拼音、首字母或省份筛选。手机可上下滑动浏览；没有找到时，在列表底部输入完整城市名，点击“添加并前往”。

    切换到“地点”或“美食”，点击添加按钮，填写名称、介绍等内容并保存。已有卡片可以编辑，分类和标签可以缩小列表范围；地点还可按4A、5A景区等级和是否已排行程筛选，多个条件同时生效。点击“清空筛选”恢复全部。内容保存到当前项目、当前城市。

    如何安排一天的行程？

    行程页每次显示一天，可用“选择行程日期”跳转，也可点击“上一天 / 下一天”。新增日期时点击“新增一天”，默认日期为已有行程的下一天，也可自行选择；创建后自动切换到新日期，已有日期不会重复添加。点击“确定当天行程”，再通过“从地点清单添加”把地点加入当天，也可添加行程，默认使用当前选中的日期。

    每个日期标题的“更多 → 删除这一天”会先显示确认提示。确认后会删除当前城市当天的全部安排（含备选）、每日设置和路线核算结果；地点、美食清单及其他日期保留。若当天内容已被同行者修改，请刷新核对后重新确认。

    在“确定当天行程”中调整地点；展开“出发地与返回地”可设置住处或车站。停留时长和时段可在地点编辑中修改。同一时段可容纳多个地点，空时段保留，可拖入地点。暂时不确定的地点可转为备选；需要保留时段的安排可锁定。新 AI 行程会填入推荐停留时长，从地点清单添加时继承已有建议；旧行程可点击“AI 补全停留时长”，预览后应用。每个地点均可手动修改，已填写的时长不会被补全操作覆盖。

    时段从上午一直到夜间 20:00–22:00，夜间无需额外开启。电脑端右侧“时段导航”显示时间和行程数量，点击可快速跳转；手机上横向滑动导航选择时段。

    如何使用 AI 旅行助手？

    点击主页蓝色的“AI 帮你，安排旅程”入口，选择需要的内容，填写日期、天数、节奏和偏好，然后生成建议。生成后先核对预览，编辑并勾选需要的内容，再确认导入；仅生成不会自动加入行程。

    想小幅修改时，在“确定当天行程”中使用“AI 微调当天安排”；想重新生成这一天的行程时，使用日期旁“更多 → AI 重排这一天”。两种建议都先预览再确认，修改后重新核对路线。重排仅替换所选日期的行程，地点、美食和其他日期保留。

    如果提示 AI 暂不可用，请联系管理员配置；仍可手动添加、编辑和规划。

    如何查看地图、交通和出行提示？

    地点卡片的“高德导航”可用于查找目的地。点击“规划路线”确认起终点，选择公交/地铁、步行、骑行或驾车，再规划本段。路线会自动保存；行程页的高德地图显示已保存的全程路线，点击可再次进入规划，默认显示全程。修改地点或顺序后，需重新规划受影响路段。已收录轨道交通图的城市还可从城市名称旁打开线路图，放大查看。

    完成当前城市的地点、顺序和路线规划后，点击“AI 生成行程提示”，确认规划完毕后生成，编辑并保存。行程草稿不再附带出行提示。已有提示仍可手动编辑或删除。美食卡片可以复制搜索词，方便粘贴到常用应用。出发前请核实营业时间、预约要求和交通情况。

    如何共享、导出和查看他人的修改？

    点击封面的“分享”，把项目链接发给同行者；项目设有密码时，再单独告知密码。每个人进入同一项目后都能共同编辑；保存的内容会自动同步，在“动态”中可以查看最近修改及署名。

    “行程”页的“导出行程”可下载 Word 或 Excel，选择当前城市或全部城市。导出包含已保存的行程和路线轨迹图（离线示意图，不含街道底图）；网页之后有更新时，需要重新下载文件。

    如果提示有人已修改，请先查看最新内容，再决定如何处理自己的草稿。删除前请核对当前城市和所选条目，并阅读确认提示。
